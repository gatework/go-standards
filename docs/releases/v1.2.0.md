# v1.2.0

- 启用 `sqlclosecheck` 和 `rowserrcheck`，检查 SQL 资源关闭及迭代结束后的错误处理。
- 启用 `contextcheck`，检查下游调用是否继承传入的 context，并明确独立生命周期操作的说明要求。
- 为 `gocritic` 固定六项正确性检查：`appendAssign`、`argOrder`、`badCall`、`badCond`、`dupArg`、`exitAfterDefer`。
- 升级时运行 `go run github.com/gatework/go-standards/cmd/stdsync@v1.2.0 write /path/to/repository`，再执行 `make check`；对分析器无法识别的回调传递或资源生命周期，只在代码处添加有理由的局部例外。
