# v1.1.0

This release strengthens the Go engineering standard and fixes checks that
previously allowed ineffective architecture rules and incomplete enum handling.

## Changes

- Add explicit rules for data semantics, ownership, algorithm correctness,
  complexity budgets, deterministic output, domain invariants and resource
  lifecycle contracts.
- Clarify when layered architecture, interfaces and functional options apply.
- Refine error wrapping, receiver consistency, naming and test isolation rules.
- Reject empty architecture configurations, multiple YAML documents and rules
  that match no production packages.
- Require explicit known enum cases and restore revive package-name checks.
- Correct Unix build-constraint guidance.

## Adoption

After this tag is published, run:

```sh
go run github.com/gatework/go-standards/cmd/stdsync@v1.1.0 write /path/to/repository
make -C /path/to/repository check
```

Review architecture selectors, enum switches and package names before upgrading.
An intentional partial switch may use a specific, explained exhaustive exception.
Keep distributed .golangci.yml and standard.mk byte-identical to this release.

## Verification

Local format, tidy, vet, lint, architecture, shuffled race tests and
